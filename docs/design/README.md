# Designs

Technical mode (ADR 0039): the architecture the owner approved before
building, one file per feature. Each lists the decisions taken and why, the
modules and seams, how it is tested and how it is sliced into work. The
table below is generated by `node "$BUILD_EASY_HOME/scripts/design.mjs" index`,
so do not edit it by hand.

A design is approved when its owner says so; the approval records a hash of
the content. Changing an approved design makes the approval stale, and the
owner approves again before work that depends on the change is built.
